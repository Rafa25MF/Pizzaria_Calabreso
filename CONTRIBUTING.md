# Como contribuir

1. Abra uma issue descrevendo problema, melhoria ou proposta.
2. Crie uma branch a partir de `main`.
3. Faça alterações pequenas e focadas, sem incluir dados pessoais ou segredos.
4. Preserve o layout existente e verifique a experiência em diferentes larguras.
5. Execute `node scripts/validate-project.mjs`.
6. Envie um pull request explicando o que mudou e como foi validado.

Use mensagens de commit objetivas, por exemplo:

```text
fix: corrige navegação do catálogo
docs: atualiza instruções de execução
```
