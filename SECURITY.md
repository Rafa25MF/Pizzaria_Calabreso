# Política de segurança

Não publique chaves, senhas, dados pessoais ou detalhes de uma vulnerabilidade
em uma issue pública.

Se encontrar um problema de segurança, use **Security → Report a vulnerability**
no GitHub ou entre em contato privadamente com o responsável pelo perfil
[@Rafa25MF](https://github.com/Rafa25MF). Inclua o arquivo afetado, uma descrição
do impacto e passos seguros para reprodução.

Este é um projeto de portfólio. Correções confirmadas serão priorizadas, mas não
há garantia de suporte ou prazo de resposta.
